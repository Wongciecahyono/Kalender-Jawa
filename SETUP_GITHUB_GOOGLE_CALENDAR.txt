================================================================================
STEP 4: SUBSCRIBE DI GOOGLE CALENDAR
================================================================================

VERSI DESKTOP:
──────────────

1. Buka: https://calendar.google.com (login dengan Google account)

2. Di sidebar kiri, cari: "Other calendars" → Klik "+"

3. Pilih: "Subscribe to calendar"

4. Paste URL raw dari GitHub:
   https://raw.githubusercontent.com/KakDu/kalender-jawa/main/kalender-jawa.ics

5. Klik "Subscribe"

6. Tunggu beberapa saat...

7. ✅ SELESAI! Kalender Jawa muncul di sidebar dengan warna-warni!

VERSI MOBILE (Google Calendar App):
───────────────────────────────────

1. Buka Google Calendar app

2. Menu → Settings → Add calendar

3. Pilih: "Subscribe to calendar"

4. Paste URL raw

5. Subscribe

6. ✅ Kalender Jawa muncul!

================================================================================
❓ FAQ & TROUBLESHOOTING
================================================================================

T: Kalender tidak muncul di Google Calendar?
J: • Cek URL raw sudah benar
  • Cek file .ics ada di GitHub (buka file, klik Raw)
  • Tunggu 24 jam untuk refresh pertama
  • Coba subscribe lagi

T: Events muncul tapi tidak lengkap?
J: • Refresh browser (Ctrl+R atau Cmd+R)
  • Logout & login Google Calendar ulang
  • Unsubscribe & subscribe lagi

T: Warna event tidak sesuai?
J: • Google Calendar punya warna standar
  • Mungkin browser cache, refresh (Ctrl+Shift+R)
  • Setiap neton punya warna default (hijau/orange/merah)

T: Berapa lama subscribe berhasil?
J: • Biasanya langsung
  • Worst case: tunggu 24 jam untuk sync pertama

T: Bisa di-edit event?
J: • Subscribe calendar = read-only
  • Untuk edit, import ke Google Calendar pribadi

T: Update kalender berapa lama?
J: • Manual update: instant setelah commit
  • Google Calendar refresh: 24 jam
  • Bisa manual refresh: Settings → Refresh
