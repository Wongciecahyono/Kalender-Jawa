💾 BUILD APK (15-30 MENIT):
================================================================================

Kalau mau native APK (bisa install seperti app biasa):

1. Extract project:
   tar -xzf kalender-jawa-v1.0.0.tar.gz
   cd kalender-jawa

2. Setup (pertama kali):
   npm install

3. Build APK:
   npm run cap:sync
   npm run cap:open android
   → Di Android Studio: Build → Build APK

4. Install ke phone:
   adb install android/app/debug/app-debug.apk
   (Atau klik "Run" di Android Studio)

Detail lengkap di INSTALASI.md

================================================================================
🌐 DEPLOY KE WEB (5 MENIT):
================================================================================

Kalau mau online di URL publik:

1. Build web:
   npm run build

2. Deploy (Vercel - paling mudah):
   npm install -g vercel
   vercel
   → Ikuti prompts
   → URL: https://kalender-jawa.vercel.app
